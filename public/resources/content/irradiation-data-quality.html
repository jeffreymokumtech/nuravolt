Executive Summary

Irradiance data is the foundation of solar PV performance monitoring. Yet poor sensor quality, improper maintenance, and calibration drift silently cost operators millions in:

  • False negatives: Real equipment failures masked by inaccurate baseline expectations
  • False positives: Healthy equipment triggering unnecessary maintenance dispatches
  • Suboptimal cleaning: Cleaning schedules based on faulty data waste resources

Why Irradiance Data Matters:

Five Root Causes of Data Quality Issues

1. Sensor Drift and Calibration

Problem: Pyranometer calibration degrades 2-5% per year without maintenance.

Impact: Performance baselines become progressively inaccurate, masking real degradation.

Solution: Quarterly calibration checks against reference sensors, annual factory recalibration.

2. Shading Misalignment

Problem: GHI sensors placed near structures or with obstructed horizons read lower than actual.

Impact: Falsely inflated PR calculations make underperforming assets appear healthy.

Solution: Proper sensor placement per IEC 61724 standards, shadow analysis verification.

3. Timestamp Synchronization Issues

Problem: Clock drift between sensors and inverters causes misaligned time series.

Impact: 14% yield loss attribution errors (IEEE study) — the worst offender.

Solution: NTP server synchronization, verification of SCADA timestamp alignment.

📊 Example: 20 MWp UAE Plant

Issue: SCADA timestamps drifted 90 seconds from irradiance logger.

Result: False alarms reduced by 40% after timestamp correction. Three genuinely underperforming strings were identified that SCADA had missed for 8 months.

4. Missing Data Handling

Problem: Gaps in irradiance data filled with inappropriate interpolation or zeros.

Impact: Averaging zero-filled gaps into PR calculations destroys accuracy.

Solution: Define clear protocols: flag gaps > 15 minutes, use clear-sky models for short gaps.

5. Soiling on the Sensor

Problem: Dust accumulates on pyranometers faster than on panels (flat glass surface).

Impact: Sensor reads artificially low, making soiled panels look "normal."

Solution: Clean sensors weekly (more frequently than panels), automate soiling detection.

Detection and Validation Methods

Three complementary approaches for validating irradiance data quality:

1. Physics-Based Validation

Compare sensor readings against theoretical clear-sky irradiance models (PVLIB, SMARTS) adjusted for local atmospheric conditions.

Method:
  • Calculate expected GHI from lat/long and time using clear-sky model
  • Compare measured GHI to expected during clear conditions
  • Flag sensors with persistent >10% deviation

2. Consensus Validation

Cross-check multiple irradiance sensors against each other within the same plant.

Validation Check Normal Range Action if Outside
Sensor-to-sensor variation < 5% Investigate outlier sensor
Clear-sky day deviation < 8% Recalibrate sensor
Timestamp alignment < 10 sec Sync NTP servers
Daily energy correlation R² > 0.95 Check sensor placement

3. ML Anomaly Detection

Machine learning models trained on historical patterns can flag:

  • Sudden step changes indicating sensor failure
  • Gradual drift patterns indicating calibration decay
  • Outlier days inconsistent with weather patterns

Practical Implementation Guide

5-Step Data Quality Checklist

  1. Sensor Calibration: Quarterly check against reference, annual factory recalibration
  2. Timestamp Sync: Verify all devices use same NTP server, check alignment monthly
  3. Outlier Detection: Automated clipping of physically impossible values (>1500 W/m²)
  4. Missing Data Protocol: Flag gaps >15 min, use clear-sky interpolation for <5 min
  5. GHI-POA Consistency: Cross-validate global horizontal vs plane-of-array readings
